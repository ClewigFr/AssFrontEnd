# Security policy

Please **don't open a public issue** for a security problem. Report it privately through GitHub: [Report a vulnerability](https://github.com/ClewigFr/AssFrontEnd/security/advisories/new) (Security tab of the repository).

Include what is affected, how to reproduce it and its impact. You'll get an answer within a week; once a fix is released, the advisory is published and you're credited if you wish.

Only the latest version on `master` is supported.
